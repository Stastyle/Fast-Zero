# איפוס מהיר (Fast Zero)

אפליקציית ווב (PWA) בעברית לעזרה באיפוס נשק על גבי איפוסון 25 מ׳: מצלמים את המטרה, מקישים על הפגיעות, ומקבלים כמה קליקים לסובב ולאיזה כיוון.

A Hebrew RTL PWA that assists rifle zeroing on the standard 25m zeroing target: photograph the target, tap the bullet hits, get click-adjustment instructions.

## תכונות

- **מחשבון איפוס** — מרכז צרור (MPI), סטייה בס״מ, והמרה לקליקים לפי פרופיל הכוונת
- **קלט ידני** — צילום המטרה והקשה על כל פגיעה (כולל החרגת פגיעה חריגה), או מטרה סכמטית ללא תמונה
- **קנה מידה אוטומטי (הנחת דף A4)** — מצלמה בתוך האפליקציה עם מסגרת יישור: מצמידים את גבולות הדף למסגרת וקנה המידה ידוע. בהיעדר גישה למצלמה: צילום נטיבי + הקשה על 4 פינות הדף (תיקון פרספקטיבה מלא בהומוגרפיה). כיול ידני בשתי נקודות נשאר כאופציה לדף שאינו A4
- **פרופילי כוונות** — מפרו רפלקס, M16/M4/תבור כוונות ברזל. הפרופילים המובנים לצפייה בלבד, אך ניתן לשכפל אותם („שכפל וערוך“) לעותק אישי; פרופילים אישיים ניתנים לעריכה מלאה
- **היסטוריה מקומית** — נשמרת במכשיר בלבד (localStorage), ללא שרת וללא חשבונות
- **עובד אופליין** — PWA עם precache מלא; מתאים לשימוש במטווח ללא קליטה

> ⚠️ ערכי ס״מ-לקליק המסופקים כברירת מחדל הם **משוערים**. יש לאמת אותם מול הוראות היצרן של הכוונת; אם הערכים שונים — שכפלו את הפרופיל המובנה וערכו את העותק.

## פיתוח

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות (vitest)
npm run build      # בדיקת טיפוסים + בנייה ל-dist
npm run preview    # הרצת הבנייה
```

הסטאק: Vite + React + TypeScript + vite-plugin-pwa + Zustand + @use-gesture/react.

כל לוגיקת החישוב (מרכז צרור, המרת פיקסלים לס״מ עם היפוך ציר Y, קליקים) מבודדת ב-`src/core/` — TypeScript טהור ללא תלות ב-DOM, עם כיסוי בדיקות מלא ב-`src/core/__tests__/`.

## פריסה

Push ל-`main` מפעיל את `.github/workflows/deploy.yml` (בדיקות → בנייה → GitHub Pages).

הגדרה חד-פעמית: **Settings → Pages → Source: GitHub Actions**.

שימו לב: `base: '/Fast-Zero/'` ב-`vite.config.ts` חייב להתאים לשם הרפוזיטורי, אחרת ה-service worker נרשם בסקופ שגוי.
